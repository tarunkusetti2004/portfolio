About

Two disciplines, one way of thinking.

Autonomous Mobile Robot with IoT Integration

An IoT-based surveillance robot on STM32F446RE with ultrasonic and flame sensors for hazard detection, an ESP32-CAM for wireless video streaming, and Wi-Fi-based remote monitoring and control.

Traffic Light Control System

An automated traffic signal controller on STM32F446RE using a Finite State Machine for Red/Yellow/Green transitions, hardware timers for precise intervals, and a 7-segment display for live countdown.

Embedded C GPIO Timers UART

Environmental Monitoring System

A Zephyr RTOS application on the STM32 Nucleo-F446RE, interfacing a BME280 sensor over I2C and streaming live temperature, humidity, and pressure data to RightTech IoT Cloud via a WE-10 Wi-Fi module.

Zephyr RTOS I2C UART IoT Cloud
GitHub ↗

Distance Monitoring System

An IoT distance-measurement system on STM32F446RE with an HC-SR04 ultrasonic sensor, using Timer Input Capture for accurate readings and publishing live data to RightTech IoT Cloud via MQTT.
